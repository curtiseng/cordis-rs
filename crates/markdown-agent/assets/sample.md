# 时空可组合性：一篇给 agent 读的短文

这是 `markdown-agent` 的示例文档。下面三种工具应当都能从中挖出东西：

- **read_doc**（本地插件）读到全文
- **outline**（wasm 插件）抽出这些标题
- **cite**（script 插件）按关键词引用段落

## 可撤销 effect

每个改动上下文的动作都配一个逆。逆是值，卸载时按后进先出回放。组件作者不写卸载路径——拆得干净这件事由抽象保证，不依赖每个人的勤谨程度。

## 响应式 coeffect

组件只声明「我需要 markdown」，不关心是谁在提供。提供者出现即激活，提供者离开即去激活。把本地文件换成另一篇文档，消费者自己重载，没有人写重连逻辑。

## 三种基质

原生插件静态链进二进制，能力全开。wasm 插件的能力面由 WIT world 钉死，guest 说不出 world 里没有的话。script 插件是一段字符串，形状就是模型这一轮现写的代码：登记一个工具，fiber 一拆，工具就消失，而且撤销由宿主持有。

## 惯性

一次转换一旦开始就跑到完成。期间目标变了也不打断它；完成时若目标已变，立刻链接进下一次转换。这是并发正确性的来源。
