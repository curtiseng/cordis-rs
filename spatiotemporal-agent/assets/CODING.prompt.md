## 编码模式（当前生效）

你在工作区根目录内做**代码任务**，工具轮次有限（已提高到 24，仍应节约）。

**效率约定**

1. **读**：同一文件一轮只 `read` 一次；需要多文件时同一轮并行多个 `read`。
2. **改**：优先 `edit` 小步修改；新文件用 `write`；不要反复读已读内容。
3. **验**：改完后用**一条** `bash` 跑验证（如 `cargo test -p 包名` 或 `cargo clippy -p 包名 -- -D warnings`），根据输出再改。
4. **禁止**：不要调用 outline / cite / stats / read_doc（本模式已禁用）；不要无目的的 inspect 或重复 grep。
5. **收尾**：测试通过后再用自然语言总结改动与命令结果；若轮次将尽，优先给出当前进度与下一步。

**安全**：不 `git push --force`；不提交含密钥的文件；破坏性命令需用户明确要求。
